# Журнал изменений

Формат: одна строка на PR. Владелец при релизе переносит накопленное из `## Unreleased`
в раздел с версией и ставит тег.

## Unreleased

## 1.7.0 — 2026-11-14

- `tools/release.py`: релиз одной командой — `Unreleased` → раздел с версией, коммит, тег,
  GitHub Release; `--dry-run` показывает план.
- Проставлены недостающие теги `v1.2.0`–`v1.6.1` и опубликован первый GitHub Release;
  правило «версию поднимаем только через `release.py`» записано в README и регламент.

## 1.6.1 — 2026-11-13

- `hermes-agent-notes`: убран раздел про изоляцию тестового стенда — правило общее и без
  операционных деталей; сериализация тяжёлых прогонов по ресурсам хоста осталась.

## 1.6.0 — 2026-11-13

- `hermes-agent-notes` публикуется: гигиена длинных сессий, подключение Desktop к удалённому
  бэкенду и раздача профиля нужны коллегам при прогонах; ссылка добавлена из `stand-ftest`.

## 1.5.0 — 2026-11-13

- `hermes-agent` возвращён к стоковой редакции и убран из репозитория: правка штатного скилла
  отвязывала его от апстрима, обновления не приходили, копия отставала на версию.
- Авторские дополнения вынесены в локальный скилл `hermes-agent-notes` (не публикуется).
- README: правило «штатные скиллы не правим» и команды `hermes skills list-modified / diff / reset`.

## 1.4.0 — 2026-11-13

- Скиллы переименованы без префикса: `certification/stand-ftest`, `certification/dist-fuzz-report-check`.
- `attack-surface-analysis` перенесён в `certification/` — публикуется по категории, `[private]` пуст.
- Удалены скиллы одноразовых задач: `codeql-cli`, `sast-cpp-without-build`, `cve-sbom-vex-mapping`.
- Обновлены перекрёстные ссылки в `related_skills`, README и примерах команд.

## 1.3.0 — 2026-11-13

- Служебные авторские скиллы переехали в `certification/tools/` (`codeql-cli`,
  `sast-cpp-without-build`, `cve-sbom-vex-mapping`) — публикуются по категории, `[publish]`
  сократился до трёх строк.
- Правило префикса `certification-` в линте отменено: значение имеет только каталог.
- Сканирование скиллов стало рекурсивным — вложенные категории (`certification/tools`)
  поддерживаются политикой и линтом.

## 1.2.0 — 2026-11-13

- Категория `certification/`: сертификационные скиллы перенесены туда, публикуются по умолчанию
  (`[defaults] publish_categories` в `publish.list`), остальные остаются локальными.
- Правило имён в линте: `certification-` только внутри категории `certification`, и наоборот.
- `contribute.sh` спрашивает категорию у скиллов вне политики (`[c]` / `[l]` / `[Enter]`);
  `publish_policy.py` получил `--classify` и вывод публикуемых по категории.
- `sync.sh --prune`: удаляет из профиля скиллы, которые политика перестала публиковать.
- Политика публикации `publish.list` + `tools/publish_policy.py`: явно задаёт, какие скиллы уходят
  в репозиторий, а какие остаются локальными; CI падает на скилле в репозитории вне `[publish]`.
- Опубликован скилл `certification/certification-dist-fuzz-report-check` (проверка материалов
  фаззинг-тестирования по Методике ВУ).

## 1.1.0 — 2026-11-13

- Процесс совместной работы: `CODEOWNERS`, CI-валидация скиллов и истории на секреты.
- Скрипты `tools/contribute.sh` (профиль → ветка → PR), `tools/sync.sh` (репозиторий → профиль),
  `tools/skill_lint.py` (фронтматтер, секреты, конфиг).
- Скилл `software-development/profile-contribution` — регламент модернизации профиля командой.
- Из скилла `certification-stand-ftest` убран конкретный IP стенда: адреса меняются от
  прогона к прогону и в скилле не фиксируются.
- Репозиторий подготовлен к публикации: лицензия MIT, README с онбордингом.

## 1.0.0 — 2026-11-13

- Первый дистрибутив профиля: SOUL.md, config.yaml без секретов, шесть авторских скиллов
  (сертификационный стенд ФСТЭК, CVE/SBOM/VEX, CodeQL, SAST C/C++, docx, hermes-agent).
